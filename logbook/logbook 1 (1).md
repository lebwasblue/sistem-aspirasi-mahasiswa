### C. Kendala Teknis & Solusi (Blockers & Mitigation)

### C. Kendala Teknis & Solusi

**Kendala / Masalah yang Dihadapi:**

-   Terjadi konflik saat menggabungkan repository lokal dengan repository GitHub karena terdapat file README.md dan .gitignore yang dibuat secara terpisah.
    
-   Perlu penyesuaian konfigurasi file agar proyek lokal dan repository GitHub memiliki struktur yang sesuai.
    

**Solusi / Solusi Alternatif yang Diambil:**

-   Melakukan pemeriksaan terhadap bagian file yang mengalami konflik.
    
-   Menggabungkan dan menyesuaikan isi README.md dan .gitignore.
    
-   Melakukan commit hasil penggabungan dan push ulang ke repository GitHub.
